# C 编码风格 — §0–§4 基线与排版

# 硬规则快速索引（详见各章节）：
# - C-01 [HIGH] 缩进 4 空格
# - C-02 [HIGH] 文件 UTF-8 无 BOM，行尾 LF
# - C-03 [HIGH] 花括号 K&R，单行也必须带 {}
# - C-11 [CRITICAL] 编译警告零容忍

## §0 优先级与基线

- 风格优先级：可读性 > 一致性 > 个人偏好
- C 标准目标：C99+（默认 C11）；允许 `static_assert` / `_Generic` / `_Alignas`
- 编译器警告必开：`-Wall -Wextra -Werror -Wshadow -Wpedantic` 保持零警告
- 安全叠加：Autosar / 安全 / 医疗 / 汽车场景在本文档之上叠加 MISRA C 2012（详见 §18）

## §1 字符、缩进与排版

- §1.1 缩进：4 空格，**禁止 tab**；编辑器关闭"按 tab 缩进"，tab 显示宽度设为 4
- §1.2 大括号缩进：函数体/控制流相对外层缩进 4 列
- §1.3 文件编码：UTF-8 **无 BOM**；行尾 LF（CRLF 仅在 Windows 工具链下保留）；保存时去除行尾空白

## §2 行长度与换行

- 全中文 < 120 字符 / 行；全英文 < 180；中英混合 < 150
- 超长行优先在运算符之后、逗号之后、函数参数之间换行
- 续行与首行对齐到一眼看出从属关系的位置；禁止横向滚动

## §3 空行

- 函数之间：留 **2 行** 空行
- 逻辑块之间：1 行空行；可用 `/* Section name */` 分节注释
- 文件开头允许 1–2 行空行后再写 `#include`
- 不要在 `return;` 这类单行末尾再补空行

## §4 花括号风格

- K&R 紧凑：开括号与关键字/函数名同行，闭括号独占一行
- **单行语句也保留花括号**（统一风格，便于后续插入断点）
- `if / else / for / while / do / switch` 一律带 `{}`；空语句块写 `{}`，**不写 `;`**
- `do { ... } while (cond);` 中 `while` 与闭括号同行，尾部分号不省略
