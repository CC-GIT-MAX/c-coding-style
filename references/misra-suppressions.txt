# MISRA C 2012 Suppressions Template
# 借鉴 xwos/xwbs/misra-c2012-suppressions.txt 的工程实用主义做法
# 本文件是模板, 项目按需复制到仓库根或代码子目录, 重命名为 .misra-suppressions 或工具识别的名字
#
# 格式 (空格或制表符分隔):
#   <rule-id>  <reason-as-comment>  <file:line or pattern>
#
# 推荐工具识别 (按工具调整):
#   - cppcheck: --suppressions-list
#   - Coverity:   cov-configure.xml (不是本格式)
#   - PC-lint / FlexeLint:  --suppress
#   - IAR / Keil / GCC MISRA 检查插件: 各工具不同
#
# 用法:
#   cppcheck --enable=all --suppressions-list=misra-suppressions.txt src/
#   或对应工具的 suppress 参数
#
# 警告: 任何一项都是对规约的破例。提交前应:
#   1. 评估是否真的无法规避 (例如硬件约束、性能硬指标)
#   2. 在 code review 中明确说明理由
#   3. 跟踪何时可以移除该 suppress (例如平台不再依赖)
#
# 规则列表 (c2012 子集,  按需增删):
